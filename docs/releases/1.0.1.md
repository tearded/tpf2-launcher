# TPF2 Multiplayer Launcher 1.0.1

Nach dem Beenden des Spiels lassen sich Updates und Kanalwechsel wieder nutzen,
ohne den Launcher neu zu starten oder den Spielstatus manuell zu aktualisieren.

- Spielstatus wird beim Zurückkehren zum Fenster, beim Kanalwechsel und im
  sichtbaren Launcher automatisch alle 2,5 Sekunden aktualisiert.
- Solange das Spiel läuft, zeigt der Hauptknopf ausdrücklich an, dass es zuerst
  geschlossen werden muss. Gesperrte Knöpfe zeigen keinen irreführenden Ladecursor.
- Gleichzeitige Statusprüfungen werden zusammengefasst. Benutzeraktionen warten
  auf eine laufende Prüfung; während Installationen starten keine Hintergrundprüfungen.

## Aktualisieren

Im bestehenden Launcher: Einstellungen -> Updates prüfen -> Launcher aktualisieren.
Alternativ kann die Setup.exe für eine neue Installation weitergegeben werden.
Vorherige Releases bleiben erhalten. Dieses Update ändert nur den Launcher.

## Prüfung und bekannte Einschränkungen

Fünf automatisierte Frontend-Regressionen prüfen Spielstart/-ende, Kanalwechsel,
konkurrierende Aktionen und Fehlerwiederholung. Frontend-Build, native Unit-Tests
und Rust-Prüfungen laufen im Release-Workflow. Kein zusätzlicher echter Spieltest.
Windows x64 / Steam-Build 35924; vor Multiplayer-Dateiänderungen müssen weiterhin
alle Spielinstanzen geschlossen sein. Der Installer besitzt kein Authenticode-
Zertifikat; die Signatur des integrierten Updaters ist davon unabhängig.
